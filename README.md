# Mini Sistema CRUD PHP & Postgresql

### Sistema web desenvolvido em PHP nativo e Postgresql para gestão de dados, com autenticação de utilizadores e controle de sessões.

## 🌼 Tecnologias Utilizadas

* **Linguagem:** PHP 
* **Banco de Dados:** Postgres 
* **Ambiente de Desenvolvimento:** VS Code
* **Controlo de Versões:** Git & GitHub

## 🌷 Estrutura do Projeto

```text
miniSistema/
├── database/       # Ficheiros de conexão à base de dados (conect.php)
├── includes/       # Componentes reutilizáveis e funções
├── login/          # Páginas de autenticação (login.php, logout.php, cadastrar.php)
├── index.php       # Página principal 
└── README.md       # Documentação do projeto
